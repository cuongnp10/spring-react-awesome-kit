# Frontend Client (React 18/19 + TypeScript + Vite + Shadcn UI)

## Architecture Overview
This frontend leverages **Shadcn UI** for primitives, **TanStack Query** for server state, and **Orval** for automatic type-safe API code generation.

```
src/
├── core/                           # Reusable UI components & infrastructure
│   ├── components/                 # DataTable, FormBuilder, Modal, Layout, UI primitives
│   ├── hooks/                      # useAuth, useDebounce, etc.
│   └── api/                        # Axios base instance with JWT interceptors
├── generated/                      # Code auto-generated by Orval (READ-ONLY)
│   └── api/                        # DTO TypeScript types, endpoints, TanStack Query hooks
└── features/                       # Independent business feature screens
    ├── auth/                       # LoginForm, RegisterForm, AuthGuard
    └── product/                    # Reference CRUD screens (ProductPage, ProductTable, ProductDialog)
```

## Prerequisites
* Node.js >= 20.x
* npm >= 10.x
